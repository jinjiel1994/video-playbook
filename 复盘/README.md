# 复盘

规矩是从一条条片子里长出来的。这里记每条片子做了什么、学到了什么，也拆别人做得好的片子。

- `每条片子学到的.md`：按做的先后，每条片子做了什么、学到了什么。
- `大理学到的.md`：车间一个月最重要的一次复盘。反响最好的一条片子，内容和形式上做对了什么，以及改了哪几条规矩。
- `参考片拆解.md`：别人做得好的几条片子，我们学到的做法（只写做法，不搬内容）。
- `开头钩子笔记.md`：读开源仓库里讲「开头钩子」的方法整理出的要点，和后来被推翻的部分。

读复盘的一个提醒：一条片子的偶然成分排除不了；只盯着好的看，有幸存者偏差。最靠得住的是：做真想做、又有很多人关心的东西，发完对一对效果。
