# 从《大理》学到的

《大理冬天的好太阳，是印度撞出来的》，19 分 31 秒的纪录长片，2026-10 发在抖音和视频号，是车间反响最好的一条。这里只记内容和形式上学到的做法。

先说限制：只有一条，偶然的成分排除不了；这些都是事后的解释，有幸存者偏差。

## 先排除：这些不是原因

| 猜的 | 实际 |
|---|---|
| 画面动得多 | 《大理》开头动得比别的片子少，最长一段静止十来秒。动得少，反而留得住 |
| 画面亮 | 有更亮的片子没起来 |
| 配音更好 | 用的音色并不比别的片子强，只是合这类片子 |
| 片子长 | 别的长片没起来 |
| 规矩守得多、审得多 | 从任务到成片约三个半小时，好几条画面规矩没守 |
| 开头「疼」 | 正相反，见下面第 3 条 |

这些都是「看不看得清、对不对得上、动得够不够」的变量。车间一个月里这些变了很多，效果没跟着变。

## 学到的，按分量排

### 1. 题自带一大群人，平台一眼认得出该推给谁

- 大理是热门旅行地，也是「旅居」的代名词。住在这儿的、去过的、正打算去的，都是现成的观众，对这个地方有感情。
- 标题、话题、满屏的地名、旁白，所有信号都指向同一群人。
- 讲一个道理的题（欲望、表达、原生家庭、营养），理论上人人相关，平台却找不到一群具体的人。信号还常常是乱的：话题挂不相干的热门；画面的比喻把人群带偏（画面像游戏，就推给玩游戏的人，进来就走）。
- 讲一个地方，本地人最买账：自己天天住的地方被讲得又美又有来历，是被看见、有面子；转给家人朋友等于夸「咱们这儿」。

### 2. 质感是放大器

- 这是唯一一条在任务里明说要「精美的、详尽的、贴合当地风格」、要跳出给定视觉、从第一性原理想的片子。
- 抖音公开的优质内容说明里，好内容看获得感、惊喜感、表达力（「拍得好不好、叙事是否有层次」）、感染力；认作优质的另走一条分发通道，照顾节奏慢、信息深的内容；「制作精良但已经批量同质化的内容」不算。
- 画面盲评（各片截四帧、去掉片名打乱，审稿人不知道反响）：《大理》质感明显最高，理由几乎一样：「地形图配宋体，像地理杂志」，其余「大多是平涂加深色渐变」。
- 质感的来源说得出：一张宣纸，三四种颜色各管一样；真实高程算出的水墨晕渲；章节卡两团墨夹一道白；章名按笔顺一笔一画写；宋体、楷体；纸纹、墨晕、印章残缺。画风就是题材自己的审美。
- 可单看质感排不出反响：质感第二的那条第一帧是黑的，没人看。**题和开头对了，质感把片子推进「优质」那一档；题不对，它救不回来。**
- 盲评还看出：同一系列几条连着看像一个模板（同一张柱状图、同一套圆角小签、同样的字幕和双色大标题）。共用代码省了工夫，也让每条长得一样。

### 3. 开头说的是世界，没有指着观众

| 片子 | 开头那句 | 对谁说 |
|---|---|---|
| 大理 | 大理冬天的好太阳，是印度撞出来的。 | 说世界（惊奇） |
| 出片 | 出去旅游，男朋友给女朋友拍照，拍丑了，她当场发火。 | 看别人（一场戏） |
| 等于没说 | 「我尽快。」这句话，永远不会错。 | 说一句人人说的话 |
| 别分析了 | 别再分析你的原生家庭了。 | 命令观众 |
| 吃全 | 把营养吃全的钱，你可能早就在花了，只是没买对。 | 算观众的账 |
| 掏钱 | 你最得意的那种大单，可能正在把客人往外推。 | 指观众的错 |
| 挠痒 | 为什么自己挠自己，不痒？ | 问观众 |

表里从上往下，开头留人的效果大致越来越差。

- 刷抖音的人是来看的。开口就说「你错了」「你在亏」，等于把看客变成被告。
- 「开头要疼」那条规矩是从《出片》读出来的，可《出片》疼的是片子里那对情侣，观众在旁边看。
- 《大理》也说「你」，全是正面的：「你在大理见过的苍山、洱海」。
- 它前 40 秒是一支完整的预告：离谱的说法 → 「还有更离谱的」→ 一串去过的人都认得的东西「背后连着同一个原因」（信息缺口：知道一点、又差一点的时候最好奇）→ 先给一半答案 → 许诺最后标在一张图上。

### 4. 第一帧是真东西

一张认得出的地图，地名全是真的。别的片子第一帧大多是一个比喻，多是暗底；比喻要先想一下才明白，刷的人不给这一下。

### 5. 一路都在给「原来如此」

几条稿子去掉片名打乱，两位审稿人逐句标「新知、翻转、劝、指、铺」：《大理》新知最密、劝人的句子几乎没有；有的长片十几分钟只有一处新知。光有新知不够：《挠痒》也密，可入口不对。

### 6. 主干是一副眼镜，不是一句劝

「大理一直夹在中间」不叫人做什么，戴上它，地形、季风、王朝、商路都解释得通。劝人的主干要观众先承认自己需要改，还要回答「你凭什么」。结尾也一样：布置作业有负担，换一双眼睛的人会想再看一遍、讲给同行的人听。

### 7. 给的是礼物：身份、谈资、一张图

转出去有面子（转给要去大理的朋友，意思是「我想到你了」）；收藏有理由（19 分钟看不完，片尾那张图明说「截下来存着」）；知识点钉在看得见的东西上，下次看见就想起来；被宏大的东西镇住的敬畏感，是最容易被转发的情绪之一。

## 一个乘法

> 有多少人本来就关心 × 平台找不找得到他们 × 第一眼认不认得出 × 每分钟给多少「原来如此」 × 质感 × 带不带得走、转不转得出 × 信不信你

是乘法：哪一项接近零，别的再好也救不回来。「看得清、对得上」是底线，不在乘号里。车间的规矩几乎都在管这条底线，乘号里的几项一直在碰运气。

## 改了哪些规矩

1. **选题门**（`../方法/选题门.md`）。
2. **开头**：前 5 秒「奇」或「有戏」，开口说世界、说别人，「账」不再必填，第一帧画真东西（`../规格/各规格.md`）。
3. **质感**：任务书写明美的要求，字体跟着题材挑，材质要有，成片审加一问「质感」（`../方法/画面规矩.md`、`../形式库/美学工具箱.md`）。
4. **开头候选的听众按平台会推给的那群人设角色**（`../方法/两道审.md`）。
5. 不做切片。

还没定的建议：听众审加一列「哦」（哪句让他第一次知道）；定主干时先试它能不能当眼镜用；结尾优先「下次你看到 X，就会想起 Y」。

## 《大理》自己的短板

两位盲评的审稿人都挑了：中段像一节历史课（没去过的人对不上今天看得见的地方）；开头那个太阳 3 分 40 秒就讲完了，后面没有同样强的悬念；第三句「你在大理见过的」会让没去过的人觉得不是说给自己的；标题许诺「大理是这样来的」，片里没讲「大理」两个字的来历。

## 一句提醒

同样又美又深、讲一个地方的片子，没起来的有很多，我们看不见。下一条多半不会这么好，不用因此怀疑方向。好题在「做的人真想做」和「很多人本来就关心」重合的地方。
