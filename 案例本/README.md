# 案例本

以前片子里踩过的坑和当时的改法。开工时不用读，碰到「什么时候翻」那一列写的情形再来查。方向在 [`../原则.md`](../原则.md)，做法在 [`../方法/`](../方法/)。

- 一条一个情形：碰到什么、当时出了什么事、怎么改的、出现过几次。
- **加之前先查**：同一类事已经有了，就在那一条上加一次、补一句，不另起一条。
- **出现两次以上**的，看能不能写进 `方法/` 或 `规格/`；能说成一句对什么题都管用的话，才考虑升进原则（原则最多八句，见原则页「这一页怎么管」）。升上去以后，这一条留着当来由，状态写「已升」。
- 只记做法，不记谁说的原话，不记账号数据。
- 整条片子的复盘在 [`片子/`](片子/)，别人的片子和读书笔记在 [`参考/`](参考/)，见文末。

| H2 | 前 20 秒每两三秒一样大东西动起来 | 最守它的两条留人最差；《大理》前 20 秒最长静止 8.5 秒，留人最好 | 复盘 |
| H3 | 开头的「账」必填 | 算观众的账留不住人，改成可以不写 | 《吃全》 |
| H4 | 「不是 A，是 B」一律不用 | 参考片最一针见血的几句都是对照句，放宽到全片最多两处 | 参考片《大脑的六亿年》 |
| H5 | 画面动得越多越好 | 《大理》开头动得最少，最长一段静止十来秒，留人最好；「动得多」本身不是目的 | 《大理》 |
