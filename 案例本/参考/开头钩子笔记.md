# 开头钩子笔记

2026-10-08，《掏钱》第二版的开头不够抓人，于是先找 GitHub 上讲故事、短视频的热门仓库参考。读了 13 个仓库，加上 MrBeast 那份流出的制作手册。下面是车间的读书笔记，压缩过。

> 先说后来的事：照这份笔记写「疼」的开头（《掏钱》《吃全》），留不住人；《大理》说世界、不指观众，留得住。2026-10-17 起开头的规矩改成「奇或有戏」，开口不指着观众（见 `../片子/大理学到的.md`、`../../规格/各规格.md`）。这份笔记里的「疼」，今天要看成「一种写法」，不是标准。

## 证据有多硬

大部分仓库只是断言。真有数据的两家：

- **youtube-agent-skill**：钩子打分拿 74 条真实开头校准过。分辨像样的开头和故意写烂的，AUC 0.83；分辨同一作者的爆款和扑街，只有 0.56，接近抛硬币。**手艺能把开头从「烂」提到「像样」，爆不爆还要看题目和时机。**所以开头要拿自己的数据验。
- **drama-skills**：一次很小的 A/B，新规则在「前 3 秒」只多了 0.1 分。用得上的一条：一屏要读的数字开场，评分都低；先列 3 个以上候选再打分，两次都选了冷开。

## 几家都认可的

1. 第一句就进正题。不打招呼、不自报家门、不说「今天聊聊」。
2. 具体：数字、场景、东西都行，数字得是真的。
3. 只抛问题，不在开头回答；一个开头只许一个承诺。
4. 第一帧画面自己会提问，不靠读字。一屏字、一屏数字开场会输。
5. 承诺要兑现：30 秒内先给一部分；标题、封面、第一帧、第一句兑现同一个承诺。
6. 一路还要再抓：第一分钟掉人最多，大约第 3、6 分钟各要再抓一次。讲解片的版本是一个反常识的事实、一句原话，或者一个重新算过的数。

（「对着『你』说」「要有赌注」两条，被我们自己的片子推翻了：开口指着观众的几条，进来就走的人明显更多。）

## 反常识怎么写

- **先找靶子**：观众会脱口而出的那个答案 A，片子要说的是 B。没有 A，造不出反常识。A 得是会刷到这条的那群人大多会信的。
- **规则反转**：把常识翻过来，第一帧直接演它的后果。
- **翻牌**：把观众会猜的答案亮在屏幕上，打勾，再砸成叉。
- 推翻之后 15–20 秒内给证据和替代说法，不然像为唱反调而唱反调。
- 只在观众真信 A 的时候才用「不是 A，是 B」；更高一点的写法是只说 B，让观众自己补出 A。

## 几种开头的写法

| 写法 | 做什么 |
|---|---|
| 离谱但讲得通 | 一个听着离谱、正文真能讲通的说法（《大理》） |
| 一场别人之间的冲突 | 半句开场，从戏中间切进去（《出片》） |
| 规则反转 | 常识翻过来，第一帧演后果 |
| 翻牌 | 亮出观众会猜的答案，打勾再打叉 |
| 冷开、先演一眼结局 | 把揭晓前一秒提到最前，开头只摆成一个问题 |
| 安静的不对劲 | 一个不该出现在这里的细节 |
| 代价自白 | 先说他付出的代价，代价要具体（慎用，容易变成指着观众） |

## 钩子怎么失效

- 钩子和正文对不上，或兑现得太晚。开头 30 秒出现断崖，先查封面、标题、第一帧对不对得上。
- 太泛，同行谁都能说。
- 像广告：亮出东西，不说它改变了什么。
- 只抛空问题（「没人说的那件事」，却不说是哪件）。
- 假数字、假代价。
- 说得太狠，或吸引来不对的人：3 秒就走，平台跟着停推。
