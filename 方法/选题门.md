# 选题门：写任务书之前先打分

来由：车间头一个月把「看得清、对得上」磨得很细，效果却没跟着变；反响最好的《大理》，差在选题和质感，不在守规矩（`../复盘/大理学到的.md`）。所以加了这道门。

## 六个问题，每个 0–2 分

| 问题 | 2 分的样子 | 0 分的样子 |
|---|---|---|
| **谁**：能不能用一个词说出这群人，够不够大？ | 「住在大理、去过大理的人」 | 「每个人都该懂的道理」 |
| **他们本来就关心吗？** | 平时就会搜、会聊（在抖音搜一下这个词，看相关视频多少赞） | 得先说服他关心 |
| **原来如此**：列得出几件大多数人不知道、又有出处的事？ | 十件以上 | 一两件，或者全是道理 |
| **跟他有关，靠的是什么？** | 他是谁、去过哪、天天看见什么 | 他哪里做错了 |
| **带得走、转得出吗？** | 有一张图或一份清单，说得出会转给谁 | 都说不出 |
| **为什么是我们讲？** | 亲身经历、手里有一手资料、离这件事近 | 谁讲都一样 |

**8 分以上做，5–7 分换个角度再打，4 分以下不做。** 分数写在任务书最前面。发之前再写一行预测，发完拿实际效果对。

## 打分时的几个提醒

- **事后打的分只当示意。** 拿这把尺子给已发的片子补打：《大理》12、《出片》9、《吃全》7、《挠痒》5、《掏钱》4，排序和反响基本一致。可那是知道结果以后打的，有后见之明。门准不准，要靠以后每条先打分、发完再对。
- **这道门漏过一样东西：题本身新不新。** 「原来如此」那一问数的是题里的冷知识；可如果题用的框架本身人人讲过，分再高，观众一听也是「又要上课」。打分时多问一句：这个框架、这个说法，观众是不是已经听腻了？（这条只出现过一次，还没写成规矩。）
- **好题在「做的人真好奇的」和「很多人本来就好奇的」重合的地方。** 只有一头的，都不算好题。
- **「关我事」不一定是说他的毛病。** 说他喜欢的、他去过的地方，也是关他的事，而且平台更容易找到这群人。
