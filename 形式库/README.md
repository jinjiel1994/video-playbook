# 形式库

![形式像搭积木：结构、画法、规格三样随便拼](../docs/img/forms.png)

同一个内容，换一种形状、换一个画出来的世界，看起来就是两条片子。做新片时，形式方案先从这里挑。分三样挑，三样可以随便拼（比如「往下追」配「一个角色一间屋」）：

- **结构**：内容是什么形状（`结构.md`）。
- **画法**：要讲的东西能画成一个什么世界（`画法.md`）。
- **规格**：发在哪、给谁刷到、多长（`../规格/`）。

美学手法（留白、对比、夸张、颜色、字、材质、动）另在 `美学工具箱.md`。

**先定观众看完带走什么，再挑形式。** 好玩的形式不等于有意义：样片看着好玩、看完说不出带走了什么，就是形式在替内容做主（案例本 A12）。

挑的是做法，不是样子：画面元素按这篇内容重写，不照搬做过的片子，也不照搬参考片。贯穿全片的比喻是一个选项，不是每条都得有。学到新的形式就加进来，写清从哪条片子学的。

## 一张速查表

| 你要讲的东西 | 可以先看 |
|---|---|
| 一个现象，答案底下还有答案 | 结构「往下追」 |
| 两样东西互相照着讲 | 结构「一组对应」 |
| 一个人、一家店怎么走过来 | 结构「一条时间线」 |
| 一个点讲透，一两分钟 | 结构「一条短链」 |
| 一种状态怎么来的，大家以为的出路也不行 | 结构「因果故事加翻面」 |
| 一样东西有很多来历，观众想带走一张图 | 结构「母题章节卡」「空位许诺→因果总图」 |
| 介绍一个产品、一种做法 | 结构「问题、反转、一场戏」，画法「代码动画加几个生视频镜头」 |
| 看不见的心理、大脑机制 | 画法「像素游戏」 |
| 对话、社交、关系 | 画法「一个小舞台，站位就是关系」 |
| 人为什么掏钱、几股想法打架 | 画法「给人画受力图」 |
| 太满、没余地、喘不过气 | 画法「水墨留白，一把尺子演到底」 |
| 一个地方的地形、气候、来历 | 画法「用真实数据作画」 |
| 一句话怎么才算说准 | 画法「桌上摆模型」 |
