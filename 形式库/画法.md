# 画法：画成一个什么世界

| 画法 | 样子 | 做过的 |
|---|---|---|
| 一个界面当舞台 | 日常的屏幕或界面就是舞台：聊天屏幕分两半、第一人称的游戏界面、夜间导航 | 《回答》四版、《登录》、《别分析了》 |
| 一个实物当舞台 | 一样东西摆在中间，人和那句话都放上去演 | 《拉伸》（瑜伽垫） |
| 一个贯穿的符号 | 一个东西代表主干，全片跟着它变 | 《出片》（一排金色的眼睛） |
| 一条贯穿的锚（参考，没做过） | 一样功能性的东西钉在画面里不动（播放头、指针、一个点），内容从它身上走过；换场不断，转场由它来带，结尾回到开头那个样子 | 参考片《节奏科普爆款》 |
| 模型加实验图 | 一个模型按章节上色，实验画成极简小图 | 参考片《大脑的六亿年》 |
| 一个角色一间屋 | 一个舞台不换，一个角色演到底，家具收放区分「看事」和「听道理」 | 参考片《空是怎么来的》；《挠痒》卡通版（没成） |
| 像素游戏 | 把内容里的机制画成游戏规则 | 《挠痒》像素版 |
| 生视频 | 视频模型生成写实镜头 | 试过，还没有做好的 |
| 代码动画加几个生视频镜头 | 有字、有数字的全用画布画，生成只做没有字、要情绪的镜头 | 参考片 Auday 发布片 |
| 一个小舞台，站位就是关系 | 回话的人站在哪（对面、讲台、云上、旁边）就是他和对方的关系 | 《接梗》 |
| 给人画受力图 | 讲道理时颜色退下去、方格纸浮上来，人变粉笔线描，胸口长出箭头 | 《掏钱》 |
| 桌上摆模型 | 一句话就是桌上摆出来的一个模型：能错的话落定，怎么都对的话只剩虚影 | 《等于没说》 |
| 水墨留白，一把尺子演到底 | 画风本身就是主干，画面里一把会升会降的尺子 | 《一口气》 |
| 用真实数据作画 | 高程算成水墨地形、气候标准值画成曲线 | 《大理》 |
| 上实下纸（候选，没做过） | 上半实拍是事实，下半在纸上续画是读法，一根结构穿过接缝 | 一条生图提示词（参考） |

## 像素游戏：把机制画成游戏规则

《挠痒》卡通版被否掉后重做的。像素不是为了好看：游戏本来就有一整套「这一下有多重」的画面语言，观众一看就懂，正好拿来演看不见的心理和大脑机制。

- **先找映射。** 把内容里的东西一一对到游戏规则上，对不上就别用。《挠痒》：自己挠 = MISS，别人碰 = 暴击，大脑的猜 = 预判，机器慢半拍 = 网络延迟，越按越重 = 伤害数字一轮比一轮大，吵架 = 「你使用了【随口一句】」。
- **第一秒就是一个游戏反差。** MISS 对暴击，钩子就在画面里。
- **段落做成关卡**，关卡卡就是章节名；不同关卡换舞台，中间一道像素擦除。
- **旁白放进游戏对话框**，像过场动画。
- **颜色照旧有含义**：天蓝 = 你以为的，珊瑚红 = 实际感觉到的。
- 注意：画面像游戏，平台就可能当游戏推（案例本 A6）。
- 代码：`../代码/lib/pixel.js`（世界画在 90×84 的小画布上放大 12 倍，精灵用色块拼、自动描边；字画在全分辨率上，照旧过检查）。

## 一个角色一间屋

从《空是怎么来的》学的：

- **一个舞台不换。** 讲生活时家具在，讲道理时家具收走、墙和地板当白板，讲完放回来。家具在不在就是「在看事」和「在听道理」的切换，不用转场。
- **一个角色演到底**，每句话他都在演；头顶一套固定的表情符号，全片不换；全画面只有他是饱和色。
- **心里的冲突画成分身**，中间隔着主干那个东西。
- **每格三层**：顶上一行小标题（「主语 · 这一格讲什么」，前半句不变），中间是画，底下一行是结论。
- **示意图自己报身份**：小标题里写「比喻」「示意」。
- **比喻讲完，落回屋里**：抽象的图后面紧跟一个日常场景演同一件事。
- 搬到竖屏上：舞台放中间，宽 960 以内；字幕放在舞台下方、底部文案区以上；小标题和结论也是功能性的字，不小于 36px（参考片折合只有 18px 上下，不学）。
- 代码：Q 版角色在 `../代码/lib/chibi.js`（2.5 头身，正侧背、十二种表情、十二个姿势，一只小伙伴）。
- 舞台要替内容做事，不为了画面而画面（案例本 C2）。

## 一条贯穿的锚（参考）

从一条讲节奏的参考片量来的（[`../案例本/参考/参考片拆解.md`](../案例本/参考/参考片拆解.md)），我们还没做过，是参考不是规矩。和「一个贯穿的符号」不同：符号代表主干、跟着内容变；锚本身几乎不变，内容从它身上演过去。和「一个舞台不换」也不同：舞台可以换，锚不换。

- **锚有功能**：它就是看内容的那个位置。参考片是时间轴上的播放头，音符走过它才响、才亮；换成别的题，可以是秤的指针、地图上的「你在这」、一条水位线。没有功能、只是装饰的，别用。
- **换场不断**：画布和插画来回换，锚一直在（插画里换配色，位置不动）。
- **转场由锚来带**：播放头变成擦除的那条边，或者长成唱针、隧道，观众的眼睛不用重新找地方。
- **首尾回到开头**：开场的一个点变成锚；结尾再回到开头那个样子。
- 代码：在 render.js 里写 `drawAnchor(t)`，`film.js` 在场景和转场之后、字幕之前画它，溶解转场不会把它淡掉；锚上的命中用 `lib/events.js` 的事件表画（[`../方法/声音.md`](../方法/声音.md)「声音上的贴」）。
- 待办：一直在动的锚，`timecheck` 会把它算成「画面有变化」，查不出锚以外 6 秒没变。真做的时候给 timecheck 加一个排除区。

## 代码动画加几个生视频镜头

从 Auday 的发布片学的：90 秒里全屏的真人镜头只有开头 7 秒，其余全是界面和代码动画，看不到一个糊字。和整条用视频模型生成的做法正好反过来。

- 有字、有数字、有界面的，全用网页画布画；生视频只做没有字、要情绪的镜头（开头一个空镜、中间一场戏、一个过场）。
- 生成的镜头多半压暗当背景，上面叠卡片和证据，瑕疵不显，几秒素材能撑十几秒，钱花得很少。
- 开头那个镜头要全屏，第一帧就是它加开场的问题。
- 生成的画面里不放字，字全叠在上面；生成镜头和画布部分用同一套颜色。

整条都用视频模型生成，难在设计不在生产：开头要有钩子，结局别太早交代，要有风险，镜头要够多，配乐别被熨平。做生视频的片子，先拆几条同类高播放短片的前 3 秒，分镜单每个镜头标它悬着或揭开哪个问题，过目以后再花钱生成。视频模型只收不含真人脸的参考图；成品图由前一个状态的图改出来，前后才对得上。

## 给人画受力图

《掏钱》讲人为什么掏钱、为什么不买。

- **舞台定在观众的位置上**：镜头站在花店柜台里面，你就是卖家。讲事时店里有颜色；讲道理时颜色退下去、方格纸浮上来、客人变粉笔线描。不用硬切就分得清。
- **箭头是想要的那股劲儿，从胸口长出来**；几股劲儿往不同方向拉，人就被拉得晃。
- **几种劲儿各一个记号，全片不换**：直箭头是发生，绕圈是继续，撞上竖杠是停下。成片审抓到过三处没守住。
- **颜色各管一样**：青绿是劲儿，金色是钱，玫瑰粉是卖的东西，淡紫是「我的看法」，讲过的变灰。

## 桌上摆模型

《等于没说》讲《逻辑哲学论》里「怎么都对的话，等于没说」：一张斜俯视的木桌，木头玩具按句子摆上桌、用完收走。能错的话落定加一圈青绿，怎么都对的只剩灰蓝虚影，说不了的是桌子上方的灯。代码里是一个简单的针孔相机。只从前面看的镜头里，前面的东西会挡后面的，道具不能一直摆着；前景人偶要站在字幕上方（案例本 C6）。

## 水墨留白，一把尺子演到底

《一口气》讲「太满、没余地、喘不过气」。

- **先找那把尺子**：主干要能换成一个看得见、会升会降的量，而且这个量本身就是那句话。「喘不过气」就是水淹到下巴：一个人站在河的剖面里，水淹到他哪儿就是他被占到哪儿。找不到这样一个量，就别用这个画法。
- **每一句都在尺子上演，不另起画面**：涨了工资水位降，开销一样样掉进水里水又涨回来；留一口气是退一步，浪从嘴下面过去。
- **画风就是比喻**：国画讲留白，墨是被占掉的，纸白是那口气。
- **一种颜色一个意思**：青绿只给「留出来的那块」，朱红只给判决的印。
- **一场到底**：镜头只跟着人移、推拉，四分多钟没有一次切。
- 一摞铜钱这种叠在一起的半透明东西要先画在一层上再整体淡（案例本 D2）；漂在水里的字别进字幕带。

## 用真实数据作画

《大理》讲一个地方的来历：山是怎么抬起来的、湖为什么在这、冬天为什么暖，这些都量得出来，就用真数据画，不画示意图。

- **高程算成水墨地形**：公开的高程瓦片（AWS Terrain Tiles，来自 SRTM）拼起来，按坡度和光照算成墨色深浅，水面单独一层；带一份坐标，地名、路线、箭头按真经纬度放。
- **气候用标准值**：WMO 和气象局的 1991—2020 年气候标准值，画成两条曲线对着比，图上写出处。
- **坐标多处核对，再反查**：先从 OpenStreetMap 取，再和 Wikidata、维基百科、GeoNames 对；画到高程图上反查（古城在不在坝子上），对不上的不用。
- **出处进简介**。
