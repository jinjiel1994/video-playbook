# 规格：发在哪、多长、守什么

归原则 1、2 管（[`../原则.md`](../原则.md)）。同一条片子，放进手机竖屏的推荐流里，第一帧就是封面，右边有点赞按钮、底下有文案挡着。这里写每个平台、每种片长要守的东西。

`片子.json` 里写两样：「平台」（抖音、视频号）和「规格」（下面那张表里的一种）。规格管长度、语速、开头门禁拦不拦；平台管界面区、封面、发布。每种规格的细则在 `各规格.md`。

## 长度和语速

| 规格 | 长度 | 语速（每分钟） | 做过的 | 开头门禁 |
|---|---|---|---|---|
| 抖音信息流短片 | 2–5 分钟 | 240–290 字，句间停顿短 | 《挠痒》2:34、《等于没说》2:37 | 拦 |
| 讲解长片（抖音） | 4–15 分钟 | 180–210 字（快的到 236） | 《登录》7:03、《吃全》8:15、《掏钱》12:54、《多问一层》14:19 | 拦 |
| 纪录长片（视频号为主） | 15–25 分钟 | 230 字上下，章节之间留章节卡 | 《大理》19:31，十二章 | 只提示 |
| 切片 | 40–70 秒 | 跟主片一样 | 从《出片》切出的一段，77 秒 | 拦（默认不做） |
| 生视频短片 | 一分钟以内 | 按镜头 | — | 只提示 |

- 片长跟着内容走，不为时长砍例子、连接、证据，也不预设上限（比如「两分钟以内」）；上表的长度是做过的范围，不是要卡的线。标准是每一段都留得住人。重复的节拍、跟主线无关的话照样删（B7）。`script.py` 的 `TARGET` 只是参考。
- 估时：成片按每秒约 3.65 字（停顿、片尾卡都算），2 分 30 秒大约 550 字。
- 语速先试每分钟 240–260 字，盲听再定。

## 平台：抖音、视频号

两个平台都是竖屏推荐流（1080×1920）。

### 第一帧就是封面

第一帧是完整画面加开场那句话，声音 0.3 秒内开始，不黑场淡入（案例本 A3）。

### 界面区：字不进去，要紧的人也不站进去

| 区 | 范围（1080×1920） |
|---|---|
| 顶部状态栏 | 上 120px |
| 右侧点赞评论栏 | x 960 以右、y 760–1560 |
| 底部文案区 | 下 280px |
| 字幕 | 最宽 860px |

`./make.sh check` 三块都查，也查人（走进走出那一下不管）。视频号的界面区还没量过，现在按抖音这三块一起躲；量过一张视频号播放页的截图，再改 `代码/lib/capture.mjs` 的 `ZONES`。

### 封面

单独设计（`cover.js`），不截片中的帧：明亮、一个重心、大字放在中段，平台裁成 3:4 也不切掉。

### 发布

- 在平台勾选「AI 生成内容」。
- 预告片和切片默认不做，点名才做。
- 发完 24 小时、3 天、7 天各回看一次效果，跟发前的预测对一对。
